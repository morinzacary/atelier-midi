# Contribuer

Les retours de compositeurs, les profils de banques documentés et les corrections sont bienvenus.

Pour un problème, ouvrez une issue avec un exemple minimal original ou librement redistribuable, le sens de conversion, le résultat attendu et obtenu. Ne publiez pas de projet personnel, de banque de sons, de clé, de manuel commercial ou de musique protégée sans autorisation.

Pour une modification, travaillez dans `src/`, ajoutez un test musical pertinent, lancez les commandes du README puis `python3 build.py`. Incluez les pages générées de `apps/` dans la proposition. Décrivez la limite corrigée et les logiciels utilisés pour vérifier le résultat.

Les profils doivent préciser les hypothèses de registre, les commandes d’articulation et les délais estimés. Ne présentez pas une compensation de latence comme universelle.

Les contributions de code sont proposées sous la licence MIT du dépôt. Aucun abonnement ChatGPT n’est nécessaire pour utiliser ou contribuer au projet.
