# Exemples originaux

Ces courts motifs synthétiques ont été créés pour les tests du projet et sont distribués sous la même licence MIT. Ils ne reprennent pas les œuvres musicales utilisées lors des essais privés.

- `esquisse-orchestrale.musicxml` : exemple à importer dans le convertisseur Partition → Maquette.
- `essai-original.mid` : deux notes de flûte, à importer dans Maquette → Partition.
